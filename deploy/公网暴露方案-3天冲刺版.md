# PestGuard 公网暴露方案（3 天冲刺版）

> 目标：10/8 前拿到一个**公网可访问**的地址，满足官方红线
> 「无法通过公网访问的作品将被视为无效参赛作品」。
>
> 现状（2026-10-05 实测）：本机 `http://127.0.0.1:8000` 已正常运行，
> `/api/health` 返回 200，首页 80 KB 正常渲染。**服务本身没问题，只差一个公网入口。**

---

## ⚠️ 已部署服务器必读（2026-10-05 追加）

若你已把项目传到云服务器（如 `<你的服务器IP>:8000`）却「首页能开、一用就报错」，
大概率是**数据库只跑了初始迁移**，`detections` 表缺
`analysis` / `references` / `crop` / `video_meta` 四列，
所有检测接口返回 500。

**完整诊断报告见 `docs/服务器故障诊断报告.md`。**

三步修复（需 SSH 密码，请自行执行）：

```bash
ssh root@<服务器IP>
cd /opt/pestguard/backend
source .venv/bin/activate            # 若有虚拟环境
python3 -m alembic upgrade head      # 关键：补齐 0002~0007 迁移
systemctl restart pestguard          # 或你原本的启动方式
```

或直接跑自动化脚本（含诊断输出 + 修复 + 验证）：

```bash
bash /opt/pestguard/tools/fix_server.sh
```

验证：打开 `http://<服务器IP>:8000/api/health`，`schema` 字段应为 `ok`。

> 新版已内置**启动期表结构自检**：迁移没跑全时，启动日志会直接点名缺哪张表哪几列，
> `/api/health` 也会返回 `mismatch: N 张表缺 M 列`。升级后这类问题不会再拖到
> 用户点按钮才暴露。

## 结论先行：走方案 A（内网穿透），不要现在买服务器

| |方案 A · 内网穿透（推荐） | 方案 B · 云服务器 Docker |
| --- | --- | --- |
| 拿到公网地址 | **10 分钟** | 2~3 天（含备案） |
| 需要买服务器 | 否 | 是 |
| 域名备案 | 不需要（用工具提供的域名） | 境内服务器 + 域名必须备案 |

## 方案 A：cpolar 内网穿透（30 分钟）

### 第 1 步：注册并下载 cpolar

1. 打开 `https://www.cpolar.com` 注册账号（手机号即可）
2. 下载 Windows 版本客户端，安装
3. 登录：`cpolar authtoken <你的 token>`（token 在 cpolar 官网「隧道管理」页获取）

### 第 2 步：建立隧道

```powershell
# 把本机 8000 端口暴露到公网
cpolar http 8000
```

成功后终端会打印两行地址：

```
Forwarding  http://cpolar.com.cn:xxxxx  ->  http://localhost:8000
Forwarding  https://xxxxx.cpolar.top   ->  http://localhost:8000
```

**用 `https://xxxxx.cpolar.top` 那个**——它是 HTTPS，摄像头拍照功能可用。
免费版每次重启会换地址，固定地址需升级付费版（可选，答辩前再买）。

### 第 3 步：同步 CORS

改 `D:\pestguard\backend\.env`：

```env
CORS_ORIGINS=https://xxxxx.cpolar.top
```

然后重启服务（`.\停止PestGuard.bat` → `.\启动PestGuard.bat`）。

### 第 4 步：验证（这四步必须全过）

- [ ] 手机**关闭 WiFi、用 4G/5G 流量**打开 `https://xxxxx.cpolar.top` —— 这是唯一有效的公网验证
- [ ] 注册一个新账号能成功
- [ ] 上传 `测试_蚜虫.jpg` 能出 4 个边界框
- [ ] 防治建议区域有内容（空的话查 `DEEPSEEK_API_KEY`）
- [ ] `/docs` 能打开

### 第 5 步：答辩当天的兜底预案

**风险**：笔记本关机、断网、隧道掉线，公网地址直接失效 = 作品当场无法访问。

**必须准备的三重兜底**：

1. **提前录一份完整的屏幕录像**（演示视频本来就要交），答辩时除现场演示外可直接播放
2. **服务设为开机自启**：`.\start.ps1` 加到 Windows 任务计划程序，触发器选「计算机启动时」
3. **准备一个备用隧道工具**（ngrok / cloudflared），cpolar 抽风时 30 秒切换

> 现场演示前务必先在**手机流量**上打开一次确认。这一步花 30 秒，能避免最坏情况。

4. 答辩结束后立刻改密码、删演示账号
