# 田间观察功能说明

图片或视频页面可先展开“补充田间信息（选填）”，填写地块、生长阶段、自述程度和笔记，再选择素材。作物选择同时适用于图片和视频。

- 图片识别后显示画质、目标大小及低置信度提示。这些是启发式提醒，不代表识别正确性；旧记录不回填画质信息。
- 结果卡片可以切换原图/标注图，打开大图后支持 100%–400% 缩放并滚动查看局部。原图接口校验账号归属。
- “田间档案 / 识别不准确”支持编辑笔记与纠错；纠错仅保存为待复核的用户说明，不覆盖模型结论。
- 点击地块名称可查看该账号同一地块的连续记录；历史页也能按地块、日期等组合筛选。
- “保存并更新建议”显式重新排队生成建议，继续受原有 AI 配额限制。仅保存档案不调用 AI。新建议按识别与不确定性、现在怎么处理、后续怎么观察、何时咨询农技人员组织。既有建议不会自动重写。
- 症状对照使用项目知识库中同科/同目的条目和原始来源说明，不把对照项当作本次检出，也不声称它们外观必然相似。
- 上传显示实际传输进度。100% 表示传输结束，不代表识别结束；连接中断时可先查历史再重试，以免重复提交。
- 视频完成/失败提醒在已登录网页的页面切换间持续工作，点击进入对应记录。它不是浏览器关闭后的系统推送。
- 观察报告下载为自包含 HTML，图片内嵌，无会话令牌或短期签名链接；可离线打开，通过浏览器菜单打印或另存 PDF。视频报告包含检出摘要，不嵌入整段视频。支持文件分享的浏览器会显示“分享已导出报告”，其余浏览器可手动分享下载文件。

## 数据迁移

后端新增 Alembic `0010_field_observation`，仅添加可空的 `observation` 与 `quality` JSON 字段，保留旧记录。部署顺序：备份数据库、运行 `alembic upgrade head`、切换代码、重启禾察并验证健康状态。代码回退时可保留这两个兼容旧版的字段，避免删除用户已保存的资料。

## 验证

- `backend/tests/test_observation.py`：画质提示、字段校验、保存/重读、地块与记录筛选、原图与比较接口归属校验、显式建议刷新。
- `tools/browser_observation.cjs`：失败重试与进度、原图与缩放、档案纠错持久化、资料对照、建议更新、自包含报告转义、响应式表单、跨页面视频提醒。
- 使用隔离数据库与模拟检测/建议服务进行浏览器验证，不调用付费 AI。真实线上模型与 AI 配置通过健康接口检查。
