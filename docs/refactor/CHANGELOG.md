# 第一轮重构记录

## 用户可见行为

- 图片识别完成后立即显示结果，AI 建议单独生成，失败时可重试。
- 图片建议与视频任务自动轮询；离线或隐藏页面暂停请求。
- 注册登录、作物选择、拍照、上传、历史、结果、参考资料、聊天、反馈、删除和视频时间线统一到 React。
- 视频显示跨帧检出次数；原始模型置信度与作物排序分数分别表达。
- 默认演示模式显示明确提示，缺少真实模型时不会宣称真实识别能力。

## 后端与部署

- 图片解码前进行并发准入，限制排队容量与等待时间；取消请求也负责文件清理。
- AI 配额移动到实际调用之前，不再拒绝本地识别。
- 视频和建议任务先持久化到数据库，再由后台巡检派发；Redis 暂时不可用时保留输入。
- 视频处理使用尝试编号、心跳和条件更新，防止超时或删除后的旧任务回写。
- 视频重试保留源文件；每次尝试使用独立结果文件，成功后再发布。
- API 查询改为只读，超时结算移到后台。
- 建议 Worker 使用独立 Redis 队列，避免长视频阻塞图片建议。
- 新增 0009 数据库迁移；历史建议保留，历史无建议记录不自动触发 AI 调用。
- API 镜像构建同一套 React 页面；Compose 扩展移到正确层级；Redis 禁用任务淘汰。
- 启动脚本只管理自身启动的进程，端口冲突时给出提示。
- 源码包恢复真实目录结构，排除环境备份、密钥、运行数据库、依赖缓存和上传数据。
