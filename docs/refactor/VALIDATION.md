新增回归覆盖：解码前准入、排队容量与超时、取消期间等待推理停止并清理文件、AI 配额不阻止识别、建议失败与重试、重复任务只调用一次 AI、过期任务拒绝旧回写、Redis 不可用时保留两个视频上传、视频重试、Windows 超大视频清理、历史加权置信度归一化。

完整浏览器流程：注册登录 → 上传图片 → 建议失败但结果可见 → 重试建议 → 查看引用 → 追问 → 反馈 → 上传视频并查看时间点 → 移动布局 → 清空 → 退出。

可复现证据：本目录的 `backend-tests.xml`、`browser-report.json`、`tested-python-dependencies.txt`、`desktop.png` 和 `mobile.png`。截图中的结果与回答均为测试模拟数据。
